# Cloud Security Portfolio

A hands-on cloud security portfolio showcasing AWS security engineering, Infrastructure as Code (IaC), DevSecOps, and cloud governance projects.

## Technologies

- AWS
- Terraform
- Docker
- Git & GitHub
- Linux (Ubuntu)
- WSL2
- Visual Studio Code

## Prerequisites

Required tooling for reproducing the lab environment:

- Windows 11
- WSL2
- Ubuntu
- Visual Studio Code
- VS Code Remote - WSL Extension
- Git
- Docker Desktop
- Terraform

### Verification

```bash
terraform version
docker --version
git --version
uname -a
```
